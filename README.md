# GX Works2 PLC Practice

GX Works2로 실습한 PLC 래더 회로를 정리하는 저장소입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| 기초 | PLC 기본 회로, 인터록, 타이머/카운터, 시퀀스, 12비트 출력 제어 |

## 목적

PLC 실습 파일을 GitHub에 저장하고, 이후 Obsidian 지식 노트로 정리하기 위한 저장소입니다.

## 정리 방식

각 실습은 GX Works2 원본 파일 `.gxw`와 PDF 출력본을 함께 보관합니다.

- `.gxw` : 원본 백업용
- `.pdf` : 회로 해석 및 복습용
- `README.md` : 학습 내용 요약용
