# PLC 기초 실습 정리

GX Works2로 실습한 PLC 기초 래더 회로를 정리한 폴더입니다.

## 실습 목록

| 날짜 | 파일 | 핵심 개념 |
|---|---|---|
| 0623 | 실습 1-1 | 기본 입력/출력, SET/RST |
| 0623 | 실습 1-2 인터록 | 인터록, 동시 출력 방지 |
| 0623 | 실습 1-3 동일출력 2개 스위치 | 하나의 출력을 여러 조건으로 제어 |
| 0630 | 카운터타이머 | 타이머, 카운터, D 레지스터 |
| 0703 | 공개문제20 | 공정 시퀀스 제어 |
| 0703 | 12bit 제어 | MOVP, H값, K3Y20, 12비트 출력 제어 |

## 파일 구성

- `.gxw` : GX Works2 원본 프로젝트 파일
- `.pdf` : 래더 회로, 디바이스 코멘트, 디바이스 사용 리스트 출력본

## 정리 목적

PLC 실습 내용을 단순히 저장하는 것이 아니라, GitHub에 백업하고 이후 Obsidian 개념 노트로 정리하기 위한 자료입니다.
